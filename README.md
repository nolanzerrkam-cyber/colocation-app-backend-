# colocation-app-backend-
This part of the application is made in JAVA.

## Environment variables
This REST API needs the following environment variables : `DB_URL` `DB_USERNAME` `DB_PASSWORD`

How to add them via IntelliJ :
- Click on Tomcat 11.0.26 on right top of the screen
- Click on Edit Configurations...
- Click on the tab Startup/Connection
- Add the environment variables by clicking the `+` button
